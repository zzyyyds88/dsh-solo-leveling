# 升级后重打补丁指南

> dsh-defaults 统一插件 = 2 个新插件（手写 ESM，源码即产物）+ 5 个同包名 fork
> （源码全部在本项目 `packages/` 内，含 `dsh-host-apiproxy` 本地副本；
> 构建产物经 profile node_modules 覆盖全局）。
> DSH 升级只覆盖全局安装包，profile 内副本**天然免疫**；需要适配的是上游 API
> 契约变化时 fork 源码的重打。

## 1. 快速恢复（无需改代码）

DSH 升级后若发现定制失效，先确认 profile 内副本是否还在：

```bash
ls ~/.dsh/profiles/web/node_modules/@deepseek-ai/ | grep -E "directory-picker|pi-ai|apiproxy"
ls ~/.dsh/profiles/web/node_modules/ | grep -E "^dsh-(client-ui-)?defaults$"
grep -A2 "dsh-defaults" ~/.dsh/profiles/web/cordis.patch.yml
```

若副本齐全，只是行为异常 → 大概率是上游契约变化，走 §2。

## 2. 重打 fork（上游升级后）

```bash
bash dsh-defaults/build.sh          # 重建 fork（tsdown；含本地 apiproxy 副本）
bash dsh-defaults/install-to-test-env.sh
scripts/test-env-stop.sh && scripts/test-env-start.sh
node dsh-defaults/verify-defaults.mjs
```

### 若构建/运行报锚点错误

按以下位置对照 upstream 源码人工适配（各 fork 改动对照本目录 `定制记录/本次diff.patch`）：

| fork | 改动点 | 可能的破坏来源 |
|---|---|---|
| `dsh-host-directory-picker-browse` | `list()` 无路径时 `configuredStartPath()` 读 `dsh-defaults.defaultWorkingDirectory` | `list` 签名、`DirectoryPicker` 基类、settings 服务 API |
| `dsh-llm` | `prepareRoutes` 注册兜底读 `dsh-defaults.defaultRetryCount` | `prepareRoutes` 结构、LlmRuntime ctx 访问 |
| `dsh-llm-deepseek` | ① `resolveAdapterOptions` 的 `fallbackRetry`；② `options()` memo 含 defaults；③ `settings/updated` 监听器 | `resolveAdapterOptions` 签名、settings 事件名、`installSettingsSection` 签名 |
| `dsh-llm-pi-ai` | ① `resolveProfiles` 的 `fallbackRetry`（重试兜底）；② `settings/updated` 监听器（重试变更重新注册）；③ 手写模型默认思考档位（既有） | `resolveRetryPolicy` 校验、settings 事件名、`installSettingsSection` 签名 |
| `dsh-host-apiproxy` | `exposedNamespaces()` 加 `dsh-defaults` | `exposedNamespaces` 结构 |

## 3. 新插件（手写，无需构建）

`packages/dsh-defaults` 与 `packages/dsh-client-ui-defaults` 是手写 ESM，
升级一般不影响（只依赖 cordis 标准机制）。若 client bundle 的
`__ModuleLoader__` 格式随上游变化，按官方 tsdown 工具链重建（参照
`dsh-task-suite/shared/tsdown.client.ts`，同源 vendored 副本）。

## 4. 升级后必查清单

- [ ] `node dsh-defaults/verify-defaults.mjs` 全 PASS
- [ ] 设置页 → 插件 → 「默认值」标签可读可写
- [ ] 改默认工作目录后，添加工作区时选择器打开即定位
- [ ] composer 模型选择器对第三方手写模型显示 off/low/medium/high
- [ ] 未声明 retryPolicy 的供应商按设置的重试次数重试（日志/行为确认）
