# DSH 升级适配指南（AI Agent 用）

> 面向**任意 AI Agent** 执行 DSH 官方升级时的强制规则与步骤。本仓库是 deepseek-harness 的 fork 整合包（自维护基线、不跟随官方更新）；官方（`@deepseek-ai/*`）升级时，本仓库的「同包名 fork」与「针对旧版限制的适配层」必须按本指南适配，否则会静默跑旧代码。

## 0. 一条铁律（每次升级先读这条）

**如果官方新版已经实现了与本仓库改动相同的功能 → 优先用官方，删掉/停用本仓库对应的 fork 或适配层。**

- 判断依据是**官方新版源码**，不是 release notes 的字面描述。
- 只有官方**没做、或官方做的方式不满足需求**时，才保留本仓库的 fork / 适配层。
- 保留时也必须把 fork **重 base 到新版官方源码**，不能继续用旧版源码。

## 2. 本仓库对 DSH 的全部改动清单（升级时逐项核对）

> 以下为 rc.2 现状（2026-08 升级核对：官方 0.1.1 未实现与下表任何补丁相同的功能，**无官方化项，全部重 base 保留**）。升级到新版本时逐行对照官方新版源码：已官方化 → 弃用 fork；未官方化 → 重 base 到新版源码。**本表是本仓库 fork/适配层映射的唯一维护处。**

- `packages/bundle/web-app`：默认 HTTPS / 0.0.0.0 监听、`cordis.patch.yml` 新增自研插件行、浏览器「文本打开」入口。

- llm 思考强度档位（`dsh-llm-deepseek` / `dsh-llm-pi-ai`）：官方已内置 → 弃用 fork，只保留重试兜底。

### 2.4 自研插件（第一方包，升级免疫）

门闸、默认值、手机端适配、桌宠、任务看板、实时统计、Git 图谱、右侧面板、图像理解、皮肤中心（maid-atelier）等自研包已整合进 harness 源码（`@deepseek-ai/dsh-*`），官方升级一般不影响；只有官方 client bundle 的加载格式变化时才需重建。清单见 [PLUGINS.md](../../PLUGINS.md)。

## 3. 升级适配流程（AI Agent 逐步执行）

1. **读官方 release notes + 源码 diff**（对照 `packages/` 新旧结构）。
2. **逐项核对 §2**：官方是否已实现同功能。
   - 已官方化 → **弃用**本仓库对应的 fork/适配层，改用官方。
   - 未官方化 → **重 base**：把对应包源码更新到新版官方源码 + 重打补丁。
3. **本地验证**（打包后全局安装起实例逐项核对全绿）。
4. **用户验收后**正式重装：`npm i -g ./dist/npm/*.tgz`（用户确认后执行）。
5. 同步更新本指南 §1 基线、AGENTS.md「关键事实」、PLUGINS.md。

## 4. 防静默过期

整合包自维护基线，DSH 官方升级后要重 base 到新版源码（§3），避免「DSH 已升级、整合包还是旧版源码」的静默问题。升级前先读 §0 铁律。

## 5. 回退

- 弃用 fork 前先 git 提交当前状态（可 revert）。
- 回退 = git revert + 重新 `pnpm run build` + 重新打包（用户执行）。

## 6. 升级记录（rc.8 → rc.2，2026-08）

- **结论**：逐项核对 §2，官方 0.1.1 未实现与任一 fork 补丁相同的功能——无官方化项，
  全部重 base 到 rc.2 源码保留；包版本统一 `0.1.1-rc.2-local.1`。
- **官方 0.1.1 主要变化**（影响后续定制开发的背景）：
  - 多模态附件链路：`attachment-local` 新增编码/归一化/请求图像处理，
    `llm-deepseek` 新增 files-api 文件上传（file-store / upload-index）。
  - 新增授权接缝 `packages/credentials/authorization`（`ctx.authorization`，
    插件主导的对话式凭据获取流程）。
  - 新增实验性 Agent Teams（`packages/experimental/agent-team`，见 `docs/subsystems/agent-team.md`）。
  - `llm-pi-ai` 新增登录/鉴权（auth / login）；`session-log-export` 新增头部操作；
    `ui-subagent` 新增谱系头；Web 端 markdown 宽表格支持。
  - 仓库层：新增 `BRAND_GUIDELINES`、`README.zh.md` / `CONTRIBUTING.zh.md` 双语文档对，
    CI 拆出 `ci-master` / `release-publish` / `release-vendor-publish` 工作流。
- **定制点复验**：默认 HTTPS / 0.0.0.0 监听、访问门闸（已并入官方 index injections 机制）、
  各设置卡（门禁/默认值/移动端适配等）需按红线 3 起实例逐项冒烟。
