# 访问门禁（Access Gate）—— 定制记录

> 记录原「全网监听与登录鉴权」改造为正式 DSH 插件「访问门禁」的**全部实际改动**。

## 一句话总结

把「全网监听与登录鉴权」定制项目（补丁 + 手写插件）重新命名为**「访问门禁」**，
并按其思路库规范改造为**正式 DSH 插件**：后端 `dsh-host-access-gate`（登录门闸/
首次设置/会话/限速/口令命名空间）+ 前端 `dsh-client-ui-access-gate`
（「设置 → 插件 → 插件配置」访问口令卡片，`settings.plugin.item`），
门闸基础改由 fork 包提供，**不再打安装包补丁**；命名空间从 `web-auth` 迁移为
`access-gate`，环境变量改用 `DSH_ACCESS_GATE_PASSWORD`（兼容旧名）。

## 为什么这么改（思路）

- **插件化而非补丁**：三个安装包补丁（webserver 门闸 / apiproxy 暴露 / connection 放行）
  已由「定制插件化改造」fork 化；本项目不再维护 `patch-*.py`，只依赖 fork + profile 插件，
  升级免疫面最大化。
- **重命名**：用户要求重新起名 → 「访问门禁」（Access Gate）。全链路命名一致
  （包名/插件 id/命名空间/环境变量），避免旧「web-auth」残留造成混淆；
  命名空间迁移由安装脚本自动完成（旧键备份后重命名，口令不丢）。
- **卡片化**：按开发规范 §2.5 强制，插件配置一律「设置 → 插件 → 插件配置」独立卡片
  （样式对齐官方网页搜索卡片），替代旧版独立标签页。

## 调试中踩的坑（重要）

1. **fork 前缀匹配带尾斜杠永不命中**：`/access-gate/`（带尾斜杠）→ 匹配逻辑是
   `pathname.startsWith(prefix + "/")`，变成双斜杠永假 → 回退到 SPA index.html。
   修正：前缀不带尾斜杠 `/access-gate`。
2. **ASSET_DIR 解析到 lib/assets**：`dirname(import.meta.url)` 是 lib/ 目录 →
   `join(dirname, "assets")` 指错位置。修正：`join(dirname, "..", "assets")`。
3. **existsSync 未导入**：原代码 `node:fs` 只导入 `mkdirSync/readFileSync/writeFileSync`，
   新增 handler 用到 `existsSync` → ReferenceError → webserver 兜底回 400（且因异常
   发生在 writeHead 之前，响应无 content-type）。修正：补导入；并给 handler 加
   try/catch（错误记 console.error，回 500 不再裸奔 400）。

# 迭代记录 3：证书按地址匹配自动更新（2026-08-16）

## 问题（用户提问）

「别的用户重新配置时，配置会更新吗？」→ 逐项核对发现：
- Caddyfile：每次重跑都重写（按当前 LAN_IP/HTTPS_PORT）→ 会更新 ✓
- `--trusted-host`：每次按当前 LAN_IP 传参 → 会更新 ✓
- 设置页参数（lanHost/httpsPort）：保存即写 settings.yaml，脚本每次读取最新值 ✓
- **证书：✗ 缺口**——原逻辑只在「缺失或 30 天内过期」时重新生成，**不校验 SAN 是否匹配
  当前地址**；换 IP/域名重配时会继续用旧证书 → 浏览器 TLS/SNI mismatch（README §8.4 的坑）。

## 修复（switch-to-https.sh）

- 生成前先比对现有证书 SAN 与当前 LAN_IP：
  - IP 形式（`^[0-9.]+$`）→ 查 `IP Address:<IP>`；域名 → 查 `DNS:<域名>`；
  - 匹配且未过期 → 复用；不匹配/缺失/快过期 → 重新生成（SAN 按 IP 或 DNS 形式）；
- 证书仍绑地址不绑端口：只改端口不会重新生成（正确）。

## 验证（真实证书只读）

- `LAN_IP=192.168.1.100`（匹配当前证书）→ 复用 ✓
- `LAN_IP=192.168.3.91` → SAN 不匹配 → 重新生成 ✓
- `LAN_IP=dsh.example.com`（域名）→ DNS SAN 不匹配 → 重新生成 ✓

     使 access-gate 命名空间暴露随 fork 生效 | `install-access-gate-plugin.mjs` |
| 2 | settings.yaml 迁移正则兼容行内对象：
     `web-auth: { password: ... }` → `access-gate: { password: ... }`（口令保留） | `install-access-gate-plugin.mjs` |
| 3 | host 插件设置 schema 给 lanHost/httpsPort 加 `.default()`：迁移后的部分文档
