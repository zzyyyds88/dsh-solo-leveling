# 升级后重打补丁指南 —— 访问门禁

> 「访问门禁」插件**升级免疫**：DSH 升级只覆盖全局安装包，而本项目全部依赖都在
> `$DSH_HOME`（profile 插件 + fork 同名覆盖）与系统服务（caddy）。升级后通常
> **什么都不用重打**，只需按 §2 重验；仅当上游 API 契约变化时才需按 §3 适配。

## 1. 依赖清单（升级后核对）

| 依赖 | 位置 | 升级后状态 |
|---|---|---|
| `dsh-host-access-gate` / `dsh-client-ui-access-gate` | `$DSH_HOME/profiles/web/node_modules/` | 免疫（误删则重跑 install-access-gate-plugin.mjs） |
| fork：`dsh-host-webserver`（registerGate）、`dsh-host-apiproxy`（access-gate 暴露）、`dsh-client-connection`（登录放行）、`dsh-client-ui-settings`（远程设置卡片：scope 一律 host） | `$DSH_HOME/profiles/web/node_modules/@deepseek-ai/` | 免疫；上游 API 变动时改 `packages/*/src` 重建（client-ui-settings 无 src，直接改 `lib/client.js`，见其 README） |
| `cordis.patch.yml`（webserver=127.0.0.1、access-gate mode:on、connection trustedHosts） | `$DSH_HOME/profiles/web/` | 免疫 |
| caddy HTTPS 反代 | `/etc/caddy/Caddyfile` + systemd | 免疫 |

## 2. 升级后的一键重验

```bash
cd <仓库根目录>/dsh-AccessGate

# 1) 确认插件与配置还在（幂等；缺失自动补齐，重复执行安全）
node install-access-gate-plugin.mjs --allow-formal

# 2) 静态 + 独立集成测试
bash verify.sh

# 3) 重启正式 dsh 后跑在线检查（会重启，需用户在 SSH 终端执行）
#    bash switch-to-https.sh <局域网IP>
#    bash verify.sh --live
```

## 3. 上游 API 契约变化时的适配

1. 看 fork 构建输出/启动日志定位破坏点（fork 源码在本项目 `packages/`，对照 `定制记录/本次diff.patch`）；
2. 按语义移植（对照 `定制记录/本次diff.patch` 与 fork 源码）：
   - **webserver**（`packages/dsh-host-webserver/src/index.ts`）：`registerGate(check)`
     门闸钩子在路由分发前执行（HTTP）与升级协商前执行（拒绝 403）；
   - **apiproxy**（`packages/dsh-host-apiproxy/src/api-proxy.ts`）：`exposedNamespaces()`
     加 `exposed.add('access-gate')`（`web-auth` 保留以兼容存量）；
   - **connection**（`packages/dsh-client-connection/src/index.ts`）：受保护方法围栏加
     `&& !(method.startsWith('settings.') && webAuthAuthed(ctx, request))`；
   - **client-ui-settings**（`packages/dsh-client-ui-settings/lib/client.js`）：`SettingsScopeBinder.bind`
     里 scope 持久化改 `"host"`（官方为 `connection.isLoopback ? "host" : "memory"`；直接改构建产物，
     套用 `packages/dsh-client-ui-settings/README.md` 中的同一行 diff）；
   - **鉴权插件**：若 `dsh-settings` / webserver 接口变化，改 `packages/dsh-host-access-gate/`
     （登录/首次设置/会话/限速逻辑）。
3. 移植后：fork 用 `./build.sh` 重建 → `install-to-test-env.sh`
   装 test-env → `test-access-gate.mjs` + `verify.sh` 全绿 → 才允许正式安装。

## 4. 回退（完全还原到无鉴权官方状态）

```bash
# ① 卸载插件（还原 cordis.patch.yml.bak + 删除插件目录）
node install-access-gate-plugin.mjs --unpatch --allow-formal
# ② 移除 fork（拷回安装时的 .bak，或删目录回退全局官方版）
# ③ 停 caddy（systemctl disable --now caddy）——若不再需要 HTTPS 入口
# ④ 重启 dsh web
```
